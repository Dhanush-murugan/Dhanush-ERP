# Dhanush-ERP

Dhanush Softwares ERP - NextGen Enterprise Human Resource & Operations Management Platform

## Features
- **Team Chat (WhatsApp Web / Slack Hybrid)**: Real-time 1-on-1 team messaging with unread badges, online presence, active contact pinning, and directory lookup.
- **Role-Based Access Control**:
  - Executive Super Admin controls for Dhanush Murugan.
  - Read-only disbursement status badges for standard employees.
  - Strict privacy isolation for employee leaves (CL, SL, PL, Comp-Off).
- **Payroll & Payslip Engine**: One-click PDF/HTML payslip generation, live disbursement tracking, and bank ledger export.
- **Attendance & Biometrics**: Integrated live punch logs, monthly registers, and shift tracking.
- **Project Kanban & Performance Analytics**: Milestone progress, ratings, and departmental KPIs.

## Technology Stack
- **Frontend**: React 18, Vite 6, Tailwind CSS, Lucide React
- **Backend**: Express.js, PostgreSQL (Neon Serverless), JWT Authentication
